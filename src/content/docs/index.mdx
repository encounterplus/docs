## For developers

Building content or tooling for Encounter+? The [schema reference](/reference/schema/) documents the
JSON format used for every import and export, [Legacy XML](/reference/legacy-xml/overview/) covers
the older import-only format, and the [URL scheme](/reference/url-scheme/) covers linking into the
app.
