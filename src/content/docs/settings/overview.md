Settings is reached from the gear button on the game screen. Everything in it is described across
the pages in this section, one page per screen in the app.

A few screens are also reachable from where you use them, not only from Settings:

- **Combat** — from the initiative window's overflow menu.
- **External Screen** — the setup half lives in Settings; what you show the players right now lives
  in the external screen controls on the game screen.
- **System Settings** — from the main screen's system button → **Settings**.

## The screens

| Screen | What it covers |
| --- | --- |
| [Content](/settings/content/) | Import, export and delete content; the package manager; the current system and campaign |
| [Combat](/settings/combat/) | How combatants are loaded, and how the initiative window looks |
| [Dice Roller](/settings/dice-roller/) | Roll visibility, the standard and 3D rollers, sound, and dice themes |
| [Battle Map](/settings/battle-map/) | Movement, token style, input gestures, performance, and line of sight |
| [External Screen](/settings/external-screen/) | The player-facing display: themes, physical setup, and AirPlay |
| [Remote Play](/settings/remote-play/) | The web server, the web client, and what connected players may touch |
| [Advanced](/settings/advanced/) | App interface, maintenance actions, and the local database |

Purchases — the Battle Map one-time purchase, the Premium subscription, Restore Purchases and the
Tip Jar — sit at the bottom of the main Settings screen and are covered on their own
[Purchases](/settings/purchases/) page.

## Rows on the main Settings screen

Most rows on the main screen open one of the pages above. Three do not:

- **Save Table Rolls** — keeps a record of each roll table result instead of discarding it after the
  roll. On by default. It sits under *Main Settings* because roll tables are rolled during play.
- **Contact** and **Rate & Review** — email, Reddit, Discord and the App Store listing.
- **About** — the privacy policy, the terms of use, **What's New** for the current release's notes,
  and the **Version** row showing the app version and build number. Quote that version when you
  report a problem.

## Settings that appear and disappear

Several rows are conditional, so a setting you are looking for may simply not be shown yet:

- **Battle Map** appears only with the Battle Map purchase.
- **Remote Play** and the 3D dice roller appear only with a Premium subscription.
- **Bottom Bar**, **Status Bar** and **Overscan** are hidden on Mac, where they do not apply.
- **Open Library Action** is hidden on iPhone, which has no second window.
- Some rows depend on another setting — **Advanced Pathfinding** only shows with **Token Movement
  Path** on, and **Include Name in Compact Style** only outside the standard initiative style.

Each page notes the condition next to the setting it applies to.

## Settings that live elsewhere

Not everything configurable is in Settings:

- **System settings** are defined by the loaded game system, not by the app. Reach them from the main
  screen's system button → **Settings**, or from Settings → Current System → **System Settings**.
  What they contain depends on the system. See [Content](/settings/content/#system-settings).
- **Map, token and creature properties** are edited on the object itself, in the library or on the
  map — not here.
